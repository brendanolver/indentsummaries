How to generate your CSV from Apparel Magic

  1. Note the indent start date. Go to Sales → Orders → All Open Orders. Find the date the first indent for the current season was received — you'll need this for the report date range.
  2. Note any orders to omit. While in All Open Orders, identify any indent orders that already have purchase orders raised against them. Make a note of those order numbers — they'll be excluded from the report.
  3. Open the Saved Report. Go to the Reports section and select the Indent Summary saved report.
  4. Select your collections. Choose the current indent collection you're working on, plus Core and Accessories.
  5. Set the date range. Enter the indent start date you noted in Step 1 as the start of the date range, through to today.
  6. Exclude omitted orders. If you noted any order numbers to omit in Step 2, exclude those from the report parameters now.
  7. Run & export. Run the report, then export it as a CSV. Drop that file into the upload zone above.

The exported CSV will drop straight into this tool and build your indent order summary automatically.
